# 棉签工厂入门地图

中文日用棉签学习网站的生产文件。包含首页、学习中心、交互生产流程、三情景成本计算器与本地筹备工作台。个人笔记、询价和访谈保存在访客自己的浏览器，不包含在仓库内。

这是已经构建的静态版本，无需在 GitHub 上安装 Node 或重新构建。`index.html` 在仓库根目录，`assets/` 保留原目录结构，`.nojekyll` 用于禁用 Jekyll 处理。

免费发布方式：使用 GitHub Free 的公开仓库，在 Settings → Pages 选择 Deploy from a branch，分支选择 main，目录选择 /(root)。使用系统分配的 github.io 地址，不需要先购买自定义域名。

公开仓库免费支持 Pages 的依据：[GitHub 官方说明](https://docs.github.com/en/pages/quickstart)。分支发布与入口文件要求：[创建 Pages 网站](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。

免费托管不代表中国大陆所有网络均已验证可达。正式分享前仍需使用目标用户的实际网络测试。

更换访问域名或浏览器后，学习记录不会自动迁移。请使用工作台的 JSON 导出、导入功能备份与恢复。
